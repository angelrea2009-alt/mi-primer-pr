# mi-primer-pr

Repositorio de práctica para aprender el flujo de trabajo con Git y GitHub: crear una rama, hacer un commit y abrir un Pull Request (PR).

## Contenido

- [`install_windows.md`](install_windows.md): guía para instalar la CLI de GitHub (`gh`) en Windows.

## Flujo de trabajo

1. Crea una rama para tu cambio: `git checkout -b mi-rama`
2. Haz tus cambios y confírmalos: `git commit -am "Describe el cambio"`
3. Sube la rama: `git push -u origin mi-rama`
4. Abre el PR: `gh pr create`
